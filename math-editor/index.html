CocoMath

CocoMath · K12 理科公式编辑器

所见即所得的公式输入，底层是语义树，不是 LaTeX 字符串。同一棵树能渲染成中式教材记号或国际记号， 能导出四种格式，也能直接喂给确定性引擎判分。页面可以直接操作。

语义 AST 内核中式教材记号 化学反应式确定性判分 可嵌入零外部依赖
这一版还没做到的： 手写与拍照识别小学竖式与脱式 有机结构式专业级 TeX 断行与字体度量 协同编辑

1公式输入

点进去直接打字。/ 分数 · ^ 上标 · _ 下标 · Tab 跳下一格 · ←→ 在树里走 · ↑↓ 换层 · Esc 跳出 · Backspace 语义删除（删分数线会把分子留下）

记号制式

切换制式，第 2 屏的 LaTeX 会跟着变。组合数在大陆教材写作 Cnm， 国际写作 \binom{n}{m}；向量大陆写 \overrightarrow{AB}，国际常写 \vec{AB}。 两种写法是同一个语义节点的两种渲染。存进库的是「组合数」这个语义，导出时才决定写成哪种记号。

2手写输入

用手指、鼠标或 Apple Pencil 直接写。识别在本机跑完，笔迹不上传。

识别结果

手写数学难的不是认字，是认结构——识别器只会说「这里有个 2」， 说不出这个 2 是平方还是乘数。结构那一层用的是本页已有的语义树，是自己的； 分类那一格是可替换的，接口为 CocoMath.setRecognizer(fn)。

3同一棵树，四种输出

LaTeX 给排版和试卷，MathML 给读屏和无障碍，UnicodeMath 给 Word/OMML 互通，语义树给判分和数据分析。字符串在这里都是导出物，存储格式是语义树。

4确定性判分

  
等价判定走引擎，不走模型。数值抽样加有理数精确比较判「对不对」，结构检查判「形式合不合要求」。
  误因由同一台引擎按错误规则跑一遍导出，不交给模型编。

5嵌进你自己的系统

  
两种接法。同页嵌入拿到实例直接调方法；跨源或需要沙箱时用 iframe 加 postMessage。
    右边那个编辑器就是用左边的代码挂上去的，改一下公式，宿主收到的回调会实时打出来。


  

    
<script src="cocomath.js"></script>

const ed = CocoMath.mount('#host', {
  notation: 'cn',           // 'cn' 中式教材 · 'intl' 国际
  value: '\\frac{1}{2}+\\frac{1}{3}'
});

ed.on('change', e => {
  save(e.getLaTeX());      // 存回题库
  a11y(e.getSpeech());     // 读屏朗读
});

// 判分：宿主传标准答案，拿回结构化结果
ed.grade('\\frac{5}{6}', {
  form: 'simplest',
  sourceLatex: '\\frac{1}{2}+\\frac{1}{3}'
});
